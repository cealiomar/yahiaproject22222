# Precious Shield — سجلّ الضمان الرقمي

صفحة واحدة يدخلها العميل بعد ما يشتري المنتج: يمسح الكود أو يكتب رقم الضمان، يشوف
المنتج والمدة والحالة، يفعّله باسم عربيته، وتطلع له شهادة رقمية فيها QR حقيقي.

HTML + CSS + JS خام. مفيش build، مفيش framework، مفيش dependency.

## 🔌 الربط بالسيرفر الحقيقي

كل الداتا الوهمية معزولة في ملف واحد: **`js/data.js`**.
فيه دالتين بس محتاج تغيّر جواهم — ابقِ نفس الأسماء ونفس شكل الـ return:

```js
window.PSApi = {
  lookup(number)          // → GET  /api/warranty/:number
  activate(number, body)  // → POST /api/warranty/:number/activate
};
```

**شكل الرد المطلوب من `lookup`:**

```js
{
  found: true,
  number: 'PS-2026-000123',
  product: { code:'PS CRYSTAL', finish:'gloss', years:10, sku:'PS-CRY-152-15' },
  status: 'pending' | 'active' | 'expired',   // أو found:false + status:'notfound'
  activation: { date, center, city, vehicle, plate, vin, phone } | null,
  expiresAt: '2036-03-13',
  daysLeft: 3501,
  totalDays: 3653
}
```

`activate(number, body)` بيرجّع نفس الشكل بس بـ `status:'active'`، ولازم يرفض
(`reject`) لو الرقم مُفعَّل قبل كده — الواجهة بتتعامل مع الحالتين.

مفيش حاجة تانية في الموقع بتلمس الداتا.

## ⚙️ حاجات مهمة اتعملت

**تايبوغرافي عربي** — الخط العربي متصل، فأي `letter-spacing` بيكسّر الكلمة.
في قسم مخصّص في الـ CSS بيصفّر الـ tracking على كل النص العربي، وبيزوّد الـ
line-height (١.٨٥ للنص، ٢.٠ للفقرات)، وبيكبّر المقاسات ٦٪ لأن العربي بيبان أصغر
من اللاتيني في نفس المقاس. الـ `.mono` مستثنى لأنه للأرقام والسيريالات اللاتينية.

**الجمع في العربي** — «١٢ سنة» مش «١٢ سنوات»، و«سنتان» مش «٢ سنوات».
`yearWord()` و `monthWord()` في `app.js` بيتعاملوا مع ده صح.

**الكونتراست** — الثيمين اتقاسوا بحساب الـ WCAG الحقيقي (مع دمج الشفافية على
الخلفية، مش على اللون المصمت). أقل نسبة: **٦٫٧١:١ في الدارك، ٥٫٤٩:١ في اللايت** —
الاتنين فوق حد AA (٤٫٥) على كل النصوص.

**الـ QR حقيقي** — مش صورة زينة. اتظبط ضد جداول المواصفة (format BCH، version
BCH، و Reed-Solomon على الـ test vector بتاع المواصفة). بيشفّر لينك التحقق فتقدر
تمسح الشهادة وترجع تفتح الصفحة بنفس الرقم.

**الـ WebGL** — شادر واحد fullscreen: شريحة فيلم حماية بتتموّج، والـ normal
بتاعها بتكسّر الضوء على لوجو الـ PS اللي تحتها. الماوس بيعمل موجات، والكليك
بيعمل موجة أكبر. لو الكارت ضعيف بيقلّل الدقة أوتوماتيك، ولو WebGL مش متاح
بيرجع لخلفية CSS من غير ما يكسر حاجة.

**اللودر مضمون** — لو الصفحة اتفتحت في تاب في الخلفية، الـ `requestAnimationFrame`
بيقف. فيه failsafe بالساعة الحقيقية عشان اللودر ما يعلّقش أبدًا، ونفس الحاجة
للأرقام العدّادة.

## 🌐 اللغة والثيم

- الافتراضي **عربي**. لو عايزه إنجليزي افتراضيًا، غيّر السطر في `js/app.js`:
  `let LANG = 'ar';`
- الثيم بيقرأ من إعدادات الجهاز أول مرة، وبعدها بيفتكر اختيار المستخدم.
- التبديل بيقلب `dir` بين `rtl` و `ltr` — كل الـ CSS متكتوب بـ logical properties
  فالتخطيط بيتقلب لوحده من غير أي كود إضافي.

## 📷 مسح الـ QR بالكاميرا

بيستخدم `BarcodeDetector` (متاح في Chrome و Edge وأندرويد).
Safari لسه مش داعمه — في الحالة دي بتظهر رسالة واضحة تقول للعميل يستخدم كاميرا
الموبايل العادية على الكود أو يكتب الرقم بإيده. مفيش مكتبة خارجية.
